# 🌍 Mitali Tours & Travels - Luxury Travel Website

A fully functional, multi-page luxury travel agency web application built with modern HTML5, Vanilla CSS3, and JavaScript (ES6+).

## 🌟 Key Features

- **Multi-Page Architecture**: Dedicated, fully working pages for each major section of the travel agency.
- **Global Booking Engine Modal**: Multi-step reservation wizard with date picker, room tier selection, guest counts, real-time price calculation, and simulated confirmation ticket.
- **Persistent Wishlist / Saved Trips**: Save favorite packages to `localStorage` with a persistent heart icon, global header badge counter, and dedicated wishlist management page.
- **Live Multi-Currency Converter**: Real-time conversion across **INR (₹)**, **USD ($)**, **EUR (€)**, and **GBP (£)**.
- **Instant Destination Quick View**: Interactive modal displaying best seasons, highlights, and starting rates for 12+ destinations.
- **Day-by-Day Itinerary Viewer**: In-depth day-by-day travel breakdown for tour packages.
- **Interactive Trip Planner Widget**: Custom holiday cost calculator and itinerary recommendation generator based on travel vibes.
- **Full-Screen Photo Lightbox**: Interactive gallery viewer with keyboard controls (Arrow keys & Esc).
- **Interactive Review Submission**: Dynamic form that stores and renders user reviews to `localStorage`.
- **Custom Trip Inquiry Engine**: Multi-step quote generator with instant inquiry reference codes.
- **Toast Notification Engine**: Animated user feedback for actions like saving trips, booking inquiries, and reviews.
